# Design System & Brand Guidelines

## Color Palette

### Primary Colors
- **Primary Blue**: `#0078D4` - Main action and focus states
- **Secondary Cyan**: `#50E6FF` - Accents and highlights
- **Dark Gray**: `#323130` - Primary text

### Status Colors
- **Success Green**: `#107C10` - Completed, healthy status
- **Warning Yellow**: `#FFB900` - At risk, pending
- **Error Red**: `#E74C3C` - Critical, errors
- **Info Blue**: `#0078D4` - Information messages

### Category Colors
- **Security**: `#D83B01` - Security-related items
- **Compliance**: `#107C10` - Compliance items
- **Skills**: `#0078D4` - Training & skills
- **General**: `#737373` - Default/neutral

## Typography

### Font Family
- **Primary**: Segoe UI, -apple-system, BlinkMacSystemFont, sans-serif
- **Monospace**: 'Courier New', monospace

### Font Sizes
- **H1**: 32px, bold
- **H2**: 24px, semibold
- **H3**: 18px, semibold
- **Body**: 14px, regular
- **Small**: 12px, regular
- **Caption**: 11px, regular

## Spacing

- **XS**: 4px
- **S**: 8px
- **M**: 16px
- **L**: 24px
- **XL**: 32px
- **2XL**: 48px

## Components

See Fluent UI documentation for component specifications and usage examples.

### Key Components
- Buttons (Primary, Secondary, Tertiary)
- Cards (Information, Interactive)
- Tables (Data display)
- Forms (Input, Dropdown, Checkbox)
- Modals (Dialogs, Confirmations)
- Notifications (Toast, Banner)

## Accessibility

- **WCAG 2.1 Level AA** compliance required
- Minimum color contrast ratio: 4.5:1 for text
- Focus indicators visible and at least 2px
- Alt text for all images
- Keyboard navigation support
- ARIA labels where appropriate

## Branding

### Logo
- Use official iDS Hub logo
- Maintain clear space around logo
- Never distort or rotate logo

### Voice & Tone
- Clear and professional
- User-focused
- Action-oriented
- Helpful and supportive
